# Product UI example sources

Checked official sites on September 29, 2026. These sources serve different purposes: use Mobbin or SaaSFrame to find comparable product screens and flows, Refactoring UI to understand visual changes, and Baymard to examine tested usability problems. Inclusion in a gallery is not evidence that a screen is good for our users. This research checks source coverage and access; it does not adjudicate screenshot quality or claim visual inspection of image pixels.

## Mobbin

- **Evidence and maintenance:** The homepage states that it adds content weekly and offers screens, UI elements, and complete flows. Its changelog contains an August 5, 2026 search update. This is stronger maintenance evidence than a current copyright year. [Library](https://mobbin.com/), [changelog](https://mobbin.com/changelog).
- **Access:** Free access limits apps/sites, excludes flows, animations and search, and permits three collections. Pro is listed at $10/month billed yearly and includes all apps/sites and flows. [Pricing](https://mobbin.com/pricing).
- **Recommended use — inference:** Find real web-app precedents for the same job, such as settings or searching, then inspect multiple states in a flow. This is a reference library; the public feature description does not establish curator explanations for why an individual treatment works.
- **Optional retrieval mechanism:** Mobbin provides an MCP service for AI agents on Pro/Team. It could make reference retrieval portable across agent tools; no connection, subscription or installation was performed here. [Official MCP page](https://mobbin.com/mcp).

## Refactoring UI

- **Instruction:** The public page explains that excessive borders create visual clutter and suggests spacing, contrasting backgrounds or shadows instead. The contents cover hierarchy, spacing and typography; the package includes tutorials for a complex form and a data-focused dashboard. [Official package and public instruction](https://refactoringui.com/).
- **Access and maintenance:** Public tactics and contents are readable. Essentials costs $99 and Complete $149, plus local taxes; both include the book and three videos. This is a purchasable instructional package. I did not find dated recent content updates on the page, so it should not be described as a continuously refreshed example library. [Package details](https://refactoringui.com/).
- **Recommended use — inference:** Best of these sources for explaining a visual transformation in developer terms: identify the hierarchy or separation problem, state the change, and show equal-content before/after evidence. Its dashboard/form coverage fits dense product UI, but the public page alone does not prove the quality of the paid examples.

## Baymard

- **Evidence and maintenance:** Its archive lists an Accounts & Self-Service research expansion on September 9, 2026 and new research on September 24. The public plan-matrix collection explicitly describes full-page screenshots annotated with research-based insights. [Research archive](https://baymard.com/research-articles/archive), [plan-matrix examples](https://baymard.com/ecommerce-design-examples/plan-matrix).
- **Access:** Public research and example pages are available; its free-plan announcement offers 50 guidelines and annotated examples after signup. Full findings require Premium. Do not assume a free public example exposes every annotation. [Free plan](https://baymard.com/blog/access-baymard-for-free), [example access limits](https://baymard.com/ecommerce-design-examples/plan-matrix).
- **Recommended use — inference:** Use the annotations to learn why a comparison, search, form or account flow causes trouble. This is stronger evidence for usability than gallery inclusion. Its ecommerce/subscription context limits direct transfer to an operational dashboard; it is not a general visual-polish authority or a matched before/after redesign collection.

## SaaSFrame

- **Coverage and maintenance:** Its live categories include dashboards, tables, analytics, add/edit, settings, billing and empty states, so it is directly relevant to product UI. Version comparisons include Hyperline pages dated January 2026; other comparisons are older. That verifies some recent captures, not a regular refresh cadence. [Library categories](https://www.saasframe.io/), [version comparisons](https://www.saasframe.io/search-updates).
- **Access:** The site offers free exploration; complete screen/flow browsing, filtering, screenshot-text search, Figma files and mobile versions are Pro features. Pricing-page plan cards show $18 monthly, $48 quarterly or $140 annually, while embedded upgrade prompts show conflicting figures. Treat the exact price as unresolved until checkout. [Pricing](https://www.saasframe.io/app/pricing).
- **Recommended use — inference:** A useful narrower alternative when the task is a SaaS dashboard or table. Actual version comparisons show change over time, but change is not proof of improvement; the inspected public pages do not provide instructional reasons comparable to Refactoring UI or Baymard.

## How to use these in a design workflow

Select a small set of references that match the target task, information density, platform and state. Record the source/capture date and what each reference demonstrates. Translate those observations into explicit decisions about hierarchy, grouping, typography, spacing and states. Review the resulting design on its own evidence; never accept it merely because it resembles a curated product. For teaching, prefer a reasoned change plus matched before/after views; keep historical redesign pairs labelled as historical comparisons. These sources already exist in the shared quality guide, so the useful improvement is this operating distinction, not adding another catalog of links.
