# Independent measurement helper defect review

Reviewed the candidate comparator, tests, measurement contract, verification guidance, and adapter template. No generator context or self-reports were used. **Return for fixes: two correctness defects and one portability defect.**

1. **P2 — JSON numeric parsing can turn unequal supplied measurements into a match.** `scripts/compare_measurements.py:213–217` converts every fractional/exponent token to binary float before comparison; the later Decimal conversion cannot recover lost digits. CLI evidence: numeric expected `10.0000000000000000`, actual `10.0000000000000001`, tolerance `0` returns matched/exit 0. Exact expected `1.0000000000000000` versus actual `1.0000000000000001` also returns matched/exit 0. Expected `0`, actual `1e-999`, tolerance `0` likewise falsely matches through underflow. The documented finite-number/typed-JSON contract states no precision limit. Preserve decimal token precision, or explicitly reject unsupported numeric representations rather than silently accepting changed values. Evidence: `/private/tmp/figma-ui-measurement-review/probes.json` and its named case directories.

2. **P2 — An output symlink loop escapes invalid-input handling and reports the mismatch exit code.** `scripts/compare_measurements.py:242` calls `Path.resolve()` outside a handler for its `RuntimeError` on Python 3.11. With otherwise matching files and `--out` pointing to a self-referential symlink, the CLI exits 1 with a traceback instead of invalid/exit 2. This conflicts with the advertised exit contract and makes an I/O failure appear to automation as a measurement mismatch. Handle path-resolution failures in the output-error path. Evidence: `/private/tmp/figma-ui-measurement-review/output_probes/symlink_loop.stderr`.

3. **P3 — Stdout does not have predictable UTF-8 behavior across environments.** `scripts/compare_measurements.py:247` uses the inherited text stream encoding. Under `PYTHONIOENCODING=ascii`, valid matching inputs containing `Café →` return invalid/exit 2; the same inputs written with `--out` succeed. Emit UTF-8 consistently for the CLI report, or emit ASCII-escaped JSON consistently if that is the chosen portable contract. Evidence: `/private/tmp/figma-ui-measurement-review/output_probes/ascii_stdout.stderr`.

Verification: all 11 supplied tests passed, including independent compensating dimensions, tolerance boundaries, missing IDs, duplicate IDs/keys, changed fixtures, numeric units, recursive Boolean-versus-number distinctions, nonfinite values, malformed JSON, and same-path/symlink/hardlink input preservation. Additional lone-surrogate probes returned invalid/exit 2 without traceback. The scope language correctly limits results to supplied measurements and preserves separate capture, authenticity, accessibility, interaction, and approval requirements. No universal threshold or additional approval gate was introduced. The helper remains proportionate and standard-library-only.

Only the report and temporary review artifacts were written; no candidate, canonical skill, app, or Figma files were edited. Test log: `/private/tmp/figma-ui-measurement-review/unit-tests.txt`.
