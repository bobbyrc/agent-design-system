# Repository guidance

This repository versions the reusable Figma UI workflow, a bounded original operational web workflow, and generic research.

- Follow the approved [global guidance](guidance/AGENTS.md) and its [evidence](guidance/EVIDENCE.md), subject to explicit user instructions and the active harness.
- For original direct-to-code operational web design, repair, or exploration, read the checkout-only [UI design entry](skills/ui-design/SKILL.md), its applicable profile/pattern and the [web workflow](docs/web-workflow.md). Native work is outside that entry.
- The shared Figma skill source in this repository is [skills/figma-ui/SKILL.md](skills/figma-ui/SKILL.md). Read its applicable stage and harness adapter for Figma-led UI work.
- Keep application-specific designs, artboards, screenshots, project evaluations, authentication, credentials, local scratch profiles, generated bundles, and real user media out of this public repository.
- Repository imports do not update the separately installed user skill. Record any future installation or canonical-source transition explicitly.
